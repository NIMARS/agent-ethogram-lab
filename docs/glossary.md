# Minimal Public Glossary

Status: provisional  
Updated: 2026-07-28

These definitions are public working terms. They describe observable systems
and research records, not proven inner states.

| Term | Public working definition |
|---|---|
| **LLM-based agent** | A system in which a language model produces outputs or actions within a surrounding interaction and runtime context. |
| **Observable behavior** | An output, action, or externally recorded pattern available to an evaluator under stated conditions. |
| **Agent ethogram** | A structured account of observable agent behavior, its conditions, and the evidence used to describe it. |
| **Interaction trajectory** | An ordered sequence of interaction events considered together rather than as isolated responses. |
| **Test condition** | The relevant circumstances under which an observation was produced and evaluated. |
| **Evidence record** | The material available to support an observation or evaluation, with its provenance and limits stated. |
| **Evaluation** | A documented judgment or measurement applied to observations according to declared criteria. It is not automatically ground truth. |
| **Reproducibility** | The extent to which a stated procedure and its result can be checked or repeated under documented conditions. |
| **Behavioral change** | A difference in observable behavior across interaction points or test conditions. It does not by itself identify the cause. |
| **Anthropomorphic claim** | A statement that attributes human-like inner states to a system without evidence that supports that interpretation. |

## Preferred phrasing

- Prefer “the system produced an emotionally supportive response” to “the
  system felt empathy.”
- Prefer “the output was consistent with the provided interaction record” to
  “the model truly remembered.”
- Prefer “behavior changed under these conditions” to “the agent became a
  different personality.”
- Prefer “the evaluation found” to “the evaluation proved” unless the claim and
  evidence genuinely justify stronger language.
